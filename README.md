## Sobre el repositorio

Este repositorio contiene los proyectos, prácticas y subproyectos realizados durante la materia de **Programación II**.

## Tecnologías

### Python

Lenguaje de programación utilizado para desarrollar los proyectos y aplicar diferentes conceptos de programación.

### Django

Framework de Python utilizado para desarrollar aplicaciones web de forma organizada.

### Odoo

Plataforma de gestión empresarial desarrollada principalmente con Python, utilizada para crear y administrar módulos y sistemas empresariales.
